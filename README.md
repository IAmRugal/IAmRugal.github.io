# William Ruiz Morales · Página personal

Sitio personal y portafolio publicado con GitHub Pages en **https://iamrugal.github.io**.

## Contenido

- Perfil profesional, competencias y herramientas
- Trayectoria laboral
- Portafolio de proyectos destacados
- Formación y certificaciones
- Intereses: running, montaña, videojuegos y fotografía
- Contacto

## Estructura

```
index.html      Página completa (HTML, CSS y JS en un solo archivo)
assets/         Imágenes (foto de perfil y, en el futuro, galería)
README.md       Este archivo
CONTEXTO.md     Decisiones de diseño, fuentes de información y pendientes
```

## Cómo actualizar

1. Editar `index.html` (directamente en GitHub con el ícono del lápiz, o pedir el cambio a Claude compartiéndole `CONTEXTO.md`).
2. Guardar con un mensaje claro, por ejemplo: `Actualizo cargo actual` o `Agrego galería de fotos`.
3. GitHub Pages publica el cambio en uno o dos minutos.

Para ver la página en el computador antes de subirla, basta con abrir `index.html` en el navegador.
